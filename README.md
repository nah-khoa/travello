# Travel Mini

## Tài liệu cấu trúc dự án

Xem [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md) để hiểu:

- trách nhiệm của từng thư mục;
- ranh giới frontend/backend;
- quy tắc phụ thuộc;
- cách lần theo một request khi debug.

## Chạy frontend

```powershell
cd frontend-new
npm install
npm run dev
```

## Chạy backend

```powershell
cd backend
python app.py
```
